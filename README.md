# ⏱️ ChronoX – Time Dashboard

**Experience Time Differently.**

ChronoX is a modern, responsive digital time dashboard built using HTML, CSS, and JavaScript. It combines a futuristic digital clock with essential time-management utilities, including a world clock, stopwatch, countdown timer, and alarm.

The application features a premium glassmorphism interface, neon-inspired digital displays, and dark and light themes.

## ✨ Features

### 🕒 Digital Clock
- Displays the current local time in real time.
- Supports 12-hour and 24-hour formats.
- Displays the current date and day.
- Futuristic digital display with neon glow effects.

### 🌍 World Clock
- Displays current time across multiple cities.
- India – Asia/Kolkata
- New York – America/New_York
- London – Europe/London
- Tokyo – Asia/Tokyo
- Automatically handles timezone differences.

### ⏱️ Stopwatch
- Start and stop functionality.
- Reset stopwatch.
- Record lap times without stopping the stopwatch.
- Displays elapsed time with precision.

### ⏳ Countdown Timer
- Set hours, minutes, and seconds.
- Start countdown.
- Pause and resume timer.
- Reset timer.
- Plays an alarm sound when the countdown reaches zero.

### 🔔 Alarm Clock
- Set an alarm for a specific time.
- Displays alarm status.
- Plays an audio notification when the alarm triggers.
- Stop the ringing alarm.
- Clear the alarm.

### 🎨 User Interface
- Dark mode and light mode.
- Glassmorphism-inspired cards.
- Neon cyan digital clock styling.
- Smooth transitions and hover effects.
- Responsive layout for different screen sizes.
- Fullscreen clock display.

## 💻 Getting Started

### Prerequisites

- A modern web browser
- Visual Studio Code (recommended)
- Live Server extension (recommended)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/ChronoX.git
```

**2. Navigate to the project folder**

```bash
cd ChronoX
```

**3. Open the project in VS Code**

```bash
code .
```

**4. Run the application**

Open `index.html` using the VS Code Live Server extension.

Alternatively, open `index.html` directly in your browser.

---

## 🌐 Deployment

ChronoX can be deployed using GitHub Pages.

1. Push the project to a GitHub repository.
2. Open the repository on GitHub.
3. Navigate to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/root` folder.
6. Click **Save**.
7. Wait for GitHub Pages to publish the website.

Your application will be available at:

```text
https://YOUR_USERNAME.github.io/ChronoX/
```
